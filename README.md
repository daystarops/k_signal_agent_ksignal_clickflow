# K Signal Agent

A Windows-first, click-to-run sourcing agent for Korean-native culture signals.

It pulls Korean web sources, renders pages with Playwright, screenshots dense layouts, uses a vision model to separate main content from ads/comments/UI, creates translated signal cards, audits translation quality, and renders a newsletter-ready Markdown + Tailwind HTML issue.

Start with `README_WINDOWS_CLICK_FLOW.md`.
