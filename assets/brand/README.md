# K-Signal logo assets

- `ksignal-logo-original.jpeg`: original uploaded logo image.
- `ksignal-logo.png`: cropped transparent PNG for templates and watermark backgrounds.
- `ksignal-logo-watermark.png`: duplicate transparent PNG for CSS watermark use.

Recommended repo path: `assets/brand/ksignal-logo.png`.
Set `.env`: `LOGO_ASSET_PATH=assets/brand/ksignal-logo.png`.
