# Article Depth Model

Issue articles follow this calm, text-led order: hero/source visual; headline, dek, and honest read time; signal sentence; original Korean receipt; English interpretation; why-now context; platform context; stakes; one context graphic; closer internet read; watch-next; receipts and provenance; correction/comment toggle; Related signals; More from Issue.

On mobile, the translation pair stacks, body type stays at least 16px with a 1.6 line height, touch targets stay 44px, diagrams use short text, and discovery strips never trap page scrolling. Visual slots are receipt crop, Korean quote, English interpretation, context flow/funnel, platform note, and watch-next frame. Every visual needs a useful alt description, source label, and rights status.

Provenance requires card and issue IDs, canonical source URL, platform and board, original language, captured/observed context when known, translation status, access status, media credit, and an explicit claim limit. A thread is evidence of a thread, never a population survey.

Read time uses visible editorial words divided by 220 words per minute, rounded up, with one additional viewing allowance only for a meaningful visual/embed. Homepage previews retain only approved headline, dek, lane, and hero; deeper interpretation, caveats, platform notes, and watch items stay article-only.

For future search/RAG, index visible context and original quotes, preserve stable machine IDs and bilingual aliases, exclude discovery chrome and hidden keyword dumps from excerpts, and retrieve source/caveat fields alongside summaries.
