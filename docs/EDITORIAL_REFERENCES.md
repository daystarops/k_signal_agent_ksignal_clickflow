# Editorial references

Inspected live with Playwright on August 9, 2026. These are working principles, not a request to imitate either publication.

## Five NYT layout lessons for K-Signal

1. Establish one unmistakable lead; size, image, and column span should settle the hierarchy immediately.
2. Attach a secondary story beside the lead, then compress supporting stories so importance is visible before reading.
3. Use rules and whitespace to create cadence. A section changes pace without needing an explanatory block.
4. Keep navigation compact and utility-driven so the front page, not the chrome, carries the editorial voice.
5. On mobile, preserve story order and hierarchy while collapsing columns into a calm vertical sequence.

## Five Vice headline lessons for K-Signal

1. Lead with concrete people, objects, places, or numbers; specificity creates appetite.
2. Put friction in the sentence: expectation versus reality, hype versus infrastructure, audience versus institution.
3. Prefer active verbs that imply consequence: fumbled, built, skipped, brought, stalled.
4. Leave one useful question open. The headline should promise an explanation, not summarize the entire article.
5. Let the writer's point of view show through a controlled phrase, while keeping claims sourced and culturally careful.

## K-Signal application

K-Signal should keep its restrained lead-secondary-supporting front page, white reading surfaces, compact lane navigation, and measured typography. Its headlines can carry more tension and attitude when the reporting supports it, but must not borrow another outlet's phrasing, manufacture conflict, speculate about private lives, or overstate a thread as consensus. Structure comes from hierarchy; appetite comes from precise stakes.
